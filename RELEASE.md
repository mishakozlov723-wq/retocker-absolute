Мгновенный живой текст: слова появляются прямо пока говоришь — их слышит сам компьютер, без интернета. Включается в настройках: «Текст» → «Скачать» (≈50 МБ, один раз).

**Что нового**
- **Мгновенный живой текст.** Модель распознавания живёт на твоём компьютере, поэтому слова бегут сразу, без задержки и без интернета. Итоговый текст всё равно пишет Groq — точно, как раньше.
- **Красивое исправление.** Когда приходит текст от Groq, по панели пробегает волна, а поправленные слова на миг подсвечиваются.
- **Цвет исправлений** — выбери в «Текст» → «Цвет исправлений» (или выключи подсветку).
- **Попробовать на своём голосе** — кнопка в настройках, чтобы сразу увидеть, как быстро модель тебя слышит.
- **В установщике** появилась галочка «Мгновенный живой текст» — модель скачается сама после установки.

**Если у тебя версия 1.0.20 или более ранняя** — один раз скачай и запусти **Retocker-Voice-Setup.exe**: он сам уберёт старую версию, настройки и ключ Groq сохранятся. Дальше обновления ставятся прямо из программы.

**Как начать**
1. Запусти **Retocker-Voice-Setup.exe**. Если Windows скажет «Windows защитил ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае» (у программы нет платной подписи).
2. Откроются настройки: во вкладке «Ключ Groq» вставь ключ и, если Groq у тебя не открывается напрямую, адрес посредника. Нажми «Проверить».
3. Поставь курсор, зажми **Ctrl + Win** и говори. Отпустил — текст вставился.

**Retocker-Voice-portable.exe** — та же программа без установки.

Программа живёт в трее (у часов). Крестик закрывает только окно настроек; выйти совсем — правой кнопкой по значку → «Выйти».
