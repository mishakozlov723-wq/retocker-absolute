**Retocker Absolute** — диктовка в любую программу Windows: зажал клавишу, сказал, отпустил — текст появился там, где курсор.

**Как начать**
1. Запусти **Retocker-Absolute-Setup.exe**. Если Windows скажет «Windows защитил ваш компьютер» — нажми «Подробнее» → «Выполнить в любом случае» (у программы нет платной подписи).
2. Откроются настройки: во вкладке «Ключ Groq» вставь ключ и, если Groq у тебя не открывается напрямую, адрес посредника. Нажми «Проверить».
3. Поставь курсор, зажми **Ctrl + Win** и говори. Отпустил — текст вставился.

**Retocker-Absolute-portable.exe** — та же программа без установки.

Программа живёт в трее (у часов). Крестик закрывает только окно настроек; выйти совсем — правой кнопкой по значку → «Выйти».
