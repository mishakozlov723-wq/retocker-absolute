# Retocker Absolute

Диктовка для Windows: зажал клавишу, сказал — текст появился там, где стоит курсор.

- Капсула внизу экрана, живой текст, «причёсывание» речи, проверка перед вставкой.
- Распознаёт Whisper (Groq) — напрямую или через свой посредник на Google Apps Script (`proxy/Code.gs`).
- Статистика: сколько слов надиктовано за день, неделю, в каких программах.

## Как устроено

- `src-tauri/` — программа на Tauri 2 (Rust): прозрачное окно-капсула поверх экрана (пропускает мышь везде,
  кроме самой капсулы), перехват горячей клавиши (`hook.rs`), вставка текста (`paste.rs`), трей, автозапуск.
- `ui/` — интерфейс. Капсула и превью в настройках работают на одном движке: части `ui/engine/*.js`
  склеиваются в `ui/engine.js` скриптом `scripts/prepare.mjs`.
- `proxy/Code.gs` — посредник для Groq (тот же код программа даёт скопировать в настройках).

Сборка — GitHub Actions (`.github/workflows/build.yml`): установщик NSIS и portable-версия, проверка на
чистой Windows (`scripts/smoke.ps1`, скриншоты — в ветке `ci-shots`). Коммит с `[release]` в сообщении
выкладывает релиз.
