# Retocker Absolute

Диктовка для Windows: зажал клавишу, сказал — текст появился там, где стоит курсор.

- Капсула внизу экрана, живой текст, «причёсывание» речи, проверка перед вставкой.
- Распознаёт Whisper (Groq) — через твой прокси на Google Apps Script или напрямую.
- Статистика: сколько слов надиктовано за день, неделю, в каких программах.

Сборка — GitHub Actions (`.github/workflows/build.yml`): Tauri 2, установщик NSIS.
